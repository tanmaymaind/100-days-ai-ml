# 100 Days of AI & ML 🤖

One small, real AI/ML project every day — the way a CS student actually
learns: build it, run it, write up what it taught you. Python, NumPy,
matplotlib, and scikit-learn along the way.

## Rules

- One day = one project, in its own folder (`day-NN-name/`).
- Every project runs end-to-end — no half-finished notebooks.
- Every project has a short write-up: the idea, the maths in brief, the result.
- No copied tutorials without understanding — each README explains the why.
